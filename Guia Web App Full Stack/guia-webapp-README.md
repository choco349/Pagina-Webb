# Guia rapida: app web full stack

Esta informacion te sirve para crear una app web con:

- Visual Studio Code
- Terminal
- Git y GitHub
- JavaScript
- Frontend con React/Vite
- Backend con Express
- Deploy en Vercel y Render
- Dominio personalizado

Orden recomendado:

1. Instalar VS Code, Node.js y Git.
2. Crear una carpeta del proyecto en VS Code.
3. Crear backend con Express.
4. Crear frontend con React/Vite.
5. Probar todo localmente.
6. Guardar con Git.
7. Subir a GitHub.
8. Desplegar frontend en Vercel.
9. Desplegar backend en Render.
10. Conectar dominio.
