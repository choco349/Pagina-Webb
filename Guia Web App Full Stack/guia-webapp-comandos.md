# Comandos importantes

## Verificar instalaciones

```bash
node -v
npm -v
git --version
```

## Crear proyecto

```bash
mkdir mi-app
cd mi-app
mkdir backend frontend
```

## Backend

```bash
cd backend
npm init -y
npm install express cors
npm run dev
```

## Frontend

```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm run dev
```

## Git

```bash
git init
git status
git add .
git commit -m "Initial full stack app"
```

## Subir a GitHub

```bash
git remote add origin https://github.com/TU_USUARIO/mi-app.git
git branch -M main
git push -u origin main
```

## Cambios futuros

```bash
git add .
git commit -m "Describe el cambio"
git push
```
